# Password Generator & Strength Analyzer

Консольна утиліта на **Python** для криптографічно стійкої генерації паролів, налаштування набору символів, оцінки надійності та збереження результатів у файл.

## Можливості

* **Криптографічна стійкість** — використовує модуль `secrets` та `SystemRandom` замість псевдовипадкового `random`.
* **Гарантія різноманітності символів** — додає щонайменше по одному символу з кожної обраної групи (`a-z`, `A-Z`, `0-9`, спецсимволи).
* **Гнучкі налаштування** — дає змогу задати довжину, кількість паролів і склад символів зі зручними значеннями за замовчуванням.
* **Аналіз складності** — оцінює пароль за бальною шкалою та підказує, як підвищити його стійкість.
* **Збереження у файл** — за запитом дописує згенеровані паролі у `passwords.txt` у кодуванні **UTF-8**.

## Вимоги та запуск

Потрібен **Python 3.9+** і жодних сторонніх пакетів — застосовується лише стандартна бібліотека.

1. Клонуйте репозиторій та перейдіть до теки проєкту:
git clone [https://github.com/username/password-generator.git](https://github.com/username/password-generator.git)
cd password-generator
2. Запустіть скрипт:
python password_generator.py

## Приклад роботи

=== Генератор та аналізатор паролів ===
Довжина пароля [14]: 16
Кількість паролів [3]: 2
Використовувати малі літери (a-z)? (Д/н):
Використовувати великі літери (A-Z)? (Д/н):
Використовувати цифри (0-9)? (Д/н):
Використовувати спецсимволи? (Д/н):

Згенеровані паролі:

1. k9#mP2$vLq8!xR4w  [Дуже надійний]
2. T7@nB5&zQw3*pL9s  [Дуже надійний]

Зберегти паролі у файл passwords.txt? (д/Н): н

> **Порада:** натисніть `Enter`, щоб обрати значення за замовчуванням, позначене у квадратних дужках або великою літерою (`Д` або `Н`).

## Оцінка надійності

| Рівень | Загальна характеристика | Типові рекомендації для покращення |
| --- | --- | --- |
| **Слабкий** | Занадто короткий або однотипний пароль | Збільшити довжину, додати різні категорії символів |
| **Середній** | Базовий рівень, вразливий до тривалого перебору | Збільшити довжину до 12–16+ символів, додати спецсимволи |
| **Надійний** | Добра стійкість для більшості акаунтів | За можливості збільшити довжину від 16 символів |
| **Дуже надійний** | Довжина від 16 символів і повний набір категорій | Додаткові зміни не потрібні |

## Безпека

* Додайте `passwords.txt` до `.gitignore`, щоб випадково не опублікувати паролі у відкритому репозиторії.
* Для постійного зберігання паролів користуйтеся спеціалізованими менеджерами паролів (`KeePassXC`, `Bitwarden` тощо).
