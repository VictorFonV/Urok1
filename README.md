Password Generator & Strength Analyzer
Консольна утиліта на Python для криптографічно стійкої генерації паролів, налаштування набору символів, оцінки їхньої надійності та пакетного експорту в текстовий файл.

Можливості
Криптографічна стійкість: використовує стандартний модуль secrets замість псевдовипадкового random.

Гарантія різноманітності символів: автоматично включає щонайменше по одному символу з кожної обраної категорії (малі літери, великі літери, цифри, спецсимволи).

Гнучке налаштування: вибір довжини, кількості згенерованих варіантів та наборів символів із розумними значеннями за замовчуванням.

Оцінка складності: аналізує кожен пароль за бальною шкалою та виводить конкретні поради щодо посилення.

Експорт у файл: за запитом дописує згенеровані паролі у passwords.txt у кодуванні UTF-8.

Вимоги
Python 3.9+

Зовнішні бібліотеки не потрібні (використовується лише стандартна бібліотека Python).

Встановлення та запуск
Клонуйте репозиторій або завантажте файл скрипта:

git clone https://github.com/username/password-generator.git
cd password-generator

Запустіть скрипт:

python password_generator.py

Приклад використання
=== Генератор та аналізатор паролів ===
Довжина пароля [14]: 16
Кількість паролів [3]: 2
Використовувати малі літери (a-z)? (Д/н):
Використовувати великі літери (A-Z)? (Д/н):
Використовувати цифри (0-9)? (Д/н):
Використовувати спецсимволи? (Д/н):

Згенеровані паролі:

k9#mP2$vLq8!xR4w  [Дуже надійний]

T7@nB5&zQw3*pL9s  [Дуже надійний]

Зберегти паролі у файл passwords.txt? (д/Н): н

Примітка: натискання Enter без введення тексту застосовує значення за замовчуванням, зазначене у квадратних дужках або великою літерою (Д / Н).

Структура проєкту
password-generator/
├── password_generator.py   # Основний скрипт генерації та оцінки паролів
├── passwords.txt           # Створюється автоматично при збереженні результатів
└── README.md               # Документація проєкту

Безпека
Не завантажуйте файл passwords.txt у публічні репозиторії — додайте його до .gitignore.

Для повсякденного зберігання паролів варто використовувати спеціалізовані менеджери паролів (KeePassXC, Bitwarden тощо).
